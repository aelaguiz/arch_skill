# North Star Investigation Bootstrap

Bootstrap mode for north-star-investigation: create or refresh the Commander's Intent doc so the next operator can run the first brutal test without reconstructing the problem.

## Goal

Create or refresh the Commander's Intent doc so the next operator can run the first brutal test without reconstructing the problem.

## Required work

- Normalize the investigation doc.
- Write the North Star, scope, and non-negotiables.
- Define the scoreboard.
- Capture the ground-truth anchors.
- Write the quant model or sanity checks.
- Rank the hypotheses.
- Propose the first 1-3 bets.
- Seed the worklog with what you inspected and what you currently believe.

## Bootstrap examples

### Good:

- "If p95 is dominated by service X, the test is to bypass X and compare the delta."
- "If the attrition model assumes 20 percent drop here, write the sanity check that proves or falsifies that."

### Weak:

- "Look around and see what seems off."
