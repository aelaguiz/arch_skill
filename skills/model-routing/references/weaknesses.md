# What each model is weak at

Read November 10, 2026. This is a dated record, and `$model-eval` updates it. Each row names the version it was seen on, because a version is its own model and a weakness doesn't carry to the next one by itself. Always run the newest version; a newer one starts from its row until it has been measured.

How firm each row is matters, so the last column says what stands behind it. "Field" means the judgment of the person who has watched these models build for months: strong evidence, and not a measurement. "The November test" means four tightly briefed builds of 2 to 12 minutes and 20 saved reviewer looks. It says nothing about long open work or rounds of fixes, which is where the field saw adding.
